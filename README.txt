ASSETS FOLDER — DocStream PDF-Cloud Website
============================================

Place your image files here and update the src attributes in index.html.

Suggested filenames:
  logo.png              — Company / product logo (PNG with transparency)
  screenshot-search.png — Screenshot of the document search screen
  screenshot-rename.png — Screenshot of the automatic rename screen
  screenshot-cloud.png  — Screenshot of the cloud panel

To add screenshots, find the placeholder blocks in index.html
(search for "<!-- Replace") and uncomment the <img> tags.

Recommended image sizes:
  logo.png:               200 × 60 px
  screenshot-search.png:  1200 × 750 px (or similar 16:10 ratio)
  screenshot-rename.png:   800 × 600 px
  screenshot-cloud.png:    800 × 600 px
